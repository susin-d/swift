# User App Features (Current)

Canonical source: `PROJECT_DOCUMENTATION.md`

## Ordering and Checkout
- Vendor discovery and menu browsing.
- Shared customer shell across Home, Orders, Cart, and Profile with persistent bottom navigation.
- Cart sync with backend.
- Promo validation and scheduled delivery support.
- Payment recovery UX (retry/fallback path).

## Orders and Tracking
- Order history and tracking.
- Orders workspace summary with direct drill-in to live tracking and review.
- ETA confidence envelope support.
- Cancellation flow with status safeguards.

## Support and Communication
- Support ticket creation.
- “My Tickets” timeline with close action.
- FAQ, email, and call support entry points.

## Growth and Account
- Profile workspace uses the same shell layout with wallet, saved places, growth, and support grouped in one account surface.
- Growth Hub screen:
  - spending summary
  - referral code generation/redeem
  - loyalty tier/points
  - subscriptions snapshot
  - entitlements view
  - refunds summary
  - account deletion controls
- Wallet balance displayed in profile.

## Account Lifecycle
- Deferred account deletion request.
- Deletion status check.
- Cancellation window support.
